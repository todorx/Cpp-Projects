# Problem 11

Write a **recursive** function that counts the number of positive integers in an integer array. The function receives the array and the total number of elements as arguments.

The function has the following prototype:

```cpp
int countPositive(int values[], int n);
```

Also write a `main()` function to test `countPositive`.

**Example:**

| Input | Result |
| ----- | ------ |
| `2`   | `1`    |
| `-2`  |        |
| `5`   |        |
