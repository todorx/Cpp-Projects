# Problem 18

Read a natural number `N`. Print the following output pattern:

```text
1234...N...4321
..............
123454321
1234321
12321
121
1
```

The pattern must be printed using a recursive function that prints one row of the form `123...K...321`.

If the task is solved without a function, up to 40% of the points can be earned. If the function is not fully recursive, up to 60% of the points can be earned.

## Example

```text
Input
6

Output
12345654321
123454321
1234321
12321
121
1
```
