# Problem 13

Write a recursive function that finds the maximum digit of a given integer.

Read an unknown number of integers from standard input until a value is entered that is not a number. For each one, print the maximum digit on a separate line.

**Note:** The recursive solution is worth 100% of the points, while the non-recursive solution is worth 70%.

**Note:** Using global variables is forbidden.

## Example

| Input  | Result |
| ------ | ------ |
| `5128` | `8`    |
| `4126` | `6`    |
| `7258` | `8`    |
