# Problem 11

Read integers from standard input until `0` is encountered. For each group of numbers (terminated by `0`), find the number that has the **largest most significant digit**.

The most significant digit is the leftmost digit (first digit) of a number. Print the number that contains the largest most significant digit. If there are multiple numbers with the same largest digit, print the first one.

**Example:**

| Input                                 | Output     |
| ------------------------------------- | ---------- |
| 3<br>234<br>534<br>0                  | 534        |
| 2<br>156<br>945<br>0                  | 945        |
| 1<br>789<br>0<br>2<br>123<br>456<br>0 | 789<br>456 |
